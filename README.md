## CMIN2 是什么线路，为什么值得单独搜

CMIN2 是中国移动的国际精品传输网，独立于老的 CMI 线路。移动宽带用户的流量回程走 CMIN2，延迟更低、晚高峰吞吐更稳——这也是它和 CN2 GIA、AS9929 并列被称为「三网高端线路」的原因。

在搬瓦工接入之前，CMIN2 线路 VPS 的选择主要集中在 DMIT、VMISS 这类主打中国优化的商家手里，价格普遍偏高。搬瓦工 2024 年 11 月把 CMIN2 拉进自己网络后，这条线的入门门槛直接从每月几十美元档拉低到了季付 49.99 美元，这是最近两年这件事最大的变化，也是现在还有人在搜这个词的原因。
